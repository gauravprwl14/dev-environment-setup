# social-posts

Generate ready-to-post social media content for X and LinkedIn from a content ideas file, each post paired with an image reference.

## What it does

Takes a content ideas file and produces platform-specific posts: punchy sub-280-character posts for X and 150-300 word storytelling posts for LinkedIn. If an `images/manifest.json` exists in the same directory, posts are automatically paired with generated images. Output includes a post calendar table for easy scheduling.

## How it works

This is an instruction-based skill. Claude generates the output directly — no scripts or external APIs required. Claude reads your ideas file, applies platform-specific formatting rules for each post, and writes a `social-posts.md` file using the Write tool.

## Usage

```
/social-posts path/to/ideas.md
```

Example:

```
/social-posts youtube-pipeline/my-video/ideas.md
```

Running the skill with no arguments prints usage instructions and stops.

## Input format

An `ideas.md` file (typically produced by `/content-ideas`) with YAML frontmatter and structured idea entries. Optionally, an `images/manifest.json` in the same directory for image pairing.

## Output format

A `social-posts.md` file saved to the same directory as the input. Example structure:

```markdown
---
source: "How AI Is Changing Software Development"
date_generated: "2026-03-20"
type: social-posts
---

# Social Posts

## X Posts

**Image:** idea-1-split-screen.png

Most developers are learning the wrong thing right now.

Syntax? AI handles it.
Prompting? That's the actual skill gap.

The engineers thriving in 2026 learned to write intent, not code.

What are you practicing?

---

## LinkedIn Posts
```

## Pipeline context

- **Receives from:** `/content-ideas` — an `ideas.md` file; optionally `/image-generator` — an `images/manifest.json`
- **Feeds into:** Your scheduling tool (Buffer, Typefully, Later) — copy posts directly from `social-posts.md`

Typical pipeline: `/yt-transcript` → `/content-summarizer` → `/content-ideas` → `/social-posts`

## Tips

- X post character counts are generated by Claude through careful counting — verify counts in your scheduling tool before posting, as final character counts depend on link expansion and media attachments.
- LinkedIn posts work best when the first line stands alone as a hook. If Claude's draft buries the lead, ask it to rewrite the opening sentence before you copy it.
- If images are not yet generated, each post will note "Generate with /image-generator" as the image reference — you can run `/image-generator` on the ideas file first and then re-run this skill to get paired references.
